**[下载 Windows 10 / 11 安装包（64 位）](https://github.com/971379621/theresa-garden-downloads/releases/latest)**

## 可以做什么

- 浏览角色档案、生平章节索引与 20 幅官方图片。
- 收听原皮肤、追悼皮肤的 76 条中文语音与 6 首背景音乐。
- 使用浅色花园界面，切换背景，折叠或拖动音乐播放器。
- 使用自己的 DeepSeek API 密钥进行带上下文的角色对话。
- 在本机保存手记、相册、会话、阅读清单，导入或导出备份。
- 选择文件夹生成只读文件清单，查看进度、搜索结果并导出。

## 安装与使用

1. 在下载页的 **Assets** 中下载 `Theresa-Garden-Setup-1.2.0.exe`，运行并选择安装位置。
2. 安装后直接打开软件，无需登录网站。资料、音乐和角色语音已随软件提供，可以离线浏览、播放。
3. 如需 AI 对话，在软件设置中填写自己的 DeepSeek API 密钥。此功能需要网络和服务商额度；网络与服务可用性以你的实际连接为准。

安装包约 147 MiB。当前没有数字签名，Windows 可能提示“未知发布者”。可在下载页取得 `SHA256SUMS.txt`，用 PowerShell 检查：

```powershell
Get-FileHash .\Theresa-Garden-Setup-1.2.0.exe -Algorithm SHA256
```

请从本仓库的正式发布页下载，并核对校验值。无需关闭系统安全防护。

## 数据与隐私

记录保存在当前 Windows 用户的本机数据目录，不会自动导入或同步网站账户。菜单“花园 → 打开本机数据文件夹”可查看位置。卸载默认保留本机记录；升级前建议导出重要资料。

API 密钥只在当前对话窗口内存中使用，不写进会话备份；退出后需要重新填写。向 DeepSeek 发送消息时，对话上下文与相关角色资料会交给该服务商处理。文件清单只读取你主动选择的文件夹中的文件名、大小和修改时间，不读取文件正文，也不会自动把文件清单发给模型。

当前没有自动更新服务，新版请从此仓库下载并安装。此应用没有手机远程控制或自动操作电脑的能力。
